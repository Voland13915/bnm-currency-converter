# BNM Currency Converter (Конвертер валют НБМ)

Десктопное приложение для точной конвертации валют по официальным курсам Национального банка Молдовы (НБМ / BNM).

## Основные возможности

- **Официальные курсы НБМ**: Получение актуальных валютных котировок в формате XML напрямую от сервера Национального банка Молдовы.
- **Точная арифметика**: Все финансовые вычисления и курсы валют используют класс `BigDecimal` (без погрешностей типов с плавающей точкой) с промежуточной точностью 10 знаков (`HALF_UP`) и округлением суммы до 2 знаков (`HALF_UP`).
- **Конвертация через MDL**: Расчет курсов между любыми парами валют через молдавский лей (MDL), включая поддержку одинаковых валют.
- **Мгновенный реверс (Swap)**: Смена направления конвертации нажатием одной кнопки (⇄) с автоматическим пересчетом.
- **Поддержка выходных и праздничных дней**: Учет правил публикации курсов НБМ — при выборе субботы или воскресенья применяется курс за предшествующую пятницу с соответствующим пояснением.
- **Поиск курсов на предшествующие даты**: Если на выбранную дату курсы не публиковались, приложение автоматически находит ближайшую дату с котировками в диапазоне до 10 дней назад.
- **Автономная работа (Offline Cache)**: Локальное сохранение последнего успешного ответа НБМ (`~/.bnm-converter/`). При недоступности сети приложение предлагает продолжить работу с сохраненными данными с указанием их даты и источника.
- **Русскоязычный интерфейс**: Полная локализация интерфейса и информативных сообщений об ошибках.

## Источник данных

Официальный XML-сервис Национального банка Молдовы:
`https://www.bnm.md/en/official_exchange_rates?get_xml=1&date=DD.MM.YYYY`

## Требования к окружению

- **Java**: Java 21 LTS или новее (JDK 21+)
- **Maven**: Apache Maven 3.8+

## Запуск приложения

Для запуска десктопного приложения выполните команду из корневого каталога проекта:

```powershell
mvn javafx:run
```
